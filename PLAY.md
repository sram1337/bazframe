# Play Mode

Use play mode to define and test Bazframe 2's product model.

## Start

1. Read `docs/design.md`.
2. Read `SCRATCHPAD.md` for unresolved questions.
3. Distinguish first-class product responsibilities from capabilities already supplied by Agent Skills, skill-library tools, Git, and coding-agent runtimes.

## Current focus

Define the first-class harness object and the relationship among:

- profiles;
- the skill library;
- project-owned skills and instructions;
- effective runtime configuration;
- import and export.

Record settled decisions in `docs/design.md` and unresolved questions in `SCRATCHPAD.md`.
